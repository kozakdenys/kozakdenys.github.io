Privacy Policy

claude-emails is a personal, non-commercial tool used only by its owner, Denys Kozak, to read his own Gmail and Google Calendar data on his own computers.

  • Data accessed: the owner's own Gmail messages and Google Calendar events, via Google APIs, with the owner's consent.
  • Use: to summarise the owner's tasks and schedule for the owner. No other people use this app.
  • Storage: OAuth tokens and derived task notes are stored only on the owner's own devices and private repositories.
  • Sharing: data is not sold, shared with third parties, or used for advertising.
  • Google API data use complies with the Google API Services User Data Policy, including the Limited Use requirements.
  • Deletion: the owner can revoke access at any time at myaccount.google.com/permissions.
